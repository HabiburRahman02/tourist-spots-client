## Project name
- Tourist spots

## Purpose
###### We all often dream of traveling. Using this website, you can plan your visits to various beautiful destinations and provide feedback. Additionally, there are several existing features, with plans to add many more exciting features in the future.


## Technologies Used  

### Frontend  
- HTML  
- Tailwind CSS  
- React  

### Backend  
- Node.js  
- Express.js  

### Database  
- MongoDB  

### Authentication & Hosting  
- Firebase  



## Features:  
- Explore various beautiful destinations to plan your trips.  
- Provide valuable feedback on the destinations you have visited.  
- View other users' feedback to help you choose the best places to visit.  
- Share your travel experiences with the community through reviews.  
- Authentication added using Firebase; private routes cannot be accessed without logging in.  
- Social login options like Google and GitHub are available for seamless access.  

We all often dream of traveling. Using this website, you can:  
- Plan visits to various beautiful destinations.  
- Share your valuable feedback.  

## Future Enhancements:  
- Many exciting features are planned to be added in the future to make the platform even better.

## Quick Commands to Run the Project

1. Clone: `git clone <repo-url>`
2. Install: `npm install`
3. Set up `.env.local` file with your Firebase credentials.
4. Run: `npm run dev`
5. Build: `npm run build`
